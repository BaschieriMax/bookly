# Sicurezza

Se trovi una vulnerabilità **non aprire una issue pubblica**: usa
[Security → Report a vulnerability](https://github.com/BaschieriMax/bookly/security/advisories/new)
(segnalazione privata di GitHub).

Controlli automatici attivi: CodeQL (C#, TypeScript, workflow), Dependabot (npm, NuGet,
GitHub Actions, Docker), audit delle dipendenze in CI. Dettagli in `docs/project-overview.md` §18.
